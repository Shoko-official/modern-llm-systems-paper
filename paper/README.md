# Paper

This directory is reserved for the paper entrypoint and assembly notes.

The first paper entrypoint will be introduced by a dedicated issue after the
section inventory and citation handoff rules are clear. Until then, this
directory should describe assembly expectations without adding scientific
content.

## Expected Role

Future files in this directory may define:

* the top-level paper entrypoint;
* how section files are included;
* how references are connected;
* how figures and tables are referenced;
* paper build notes once a build path exists.

## Repository Boundary

This repository owns paper structure, wording, citations, figures, and final
assembly.

It should not become the research ledger. Source records, claim records,
evidence status, and raw review notes belong in the ledger until they are ready
for paper use.

## Current Limits

Do not add scientific prose, real bibliography entries, generated figures, or a
LaTeX build system from this layout issue.
