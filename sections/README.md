# Sections

This directory is reserved for paper section files.

Section files should be added only after the section inventory is approved.
Early section files should stay narrow, reviewable, and traceable to ledger
evidence when they introduce claims.

## Expected Role

Future files in this directory may contain:

* section stubs;
* draft section prose;
* local notes about section structure;
* placeholders for figures, tables, or citations.

## Current Limits

This directory does not yet contain scientific section drafts. Do not add claims
or conclusions here until the relevant source and claim records are ready in the
research ledger.
