# Roadmap

This roadmap is intentionally limited to paper governance and bootstrap work. Scientific drafting starts only after the required research and citation foundations exist.

## Milestone 0: Project Governance

Goal: establish a small, reviewable operating model for the paper repository.

### Paper Repository Issues

1. [#1 Create paper governance documentation](https://github.com/Shoko-official/modern-llm-systems-paper/issues/1)
2. [#2 Add paper issue and MR templates](https://github.com/Shoko-official/modern-llm-systems-paper/issues/2)
3. [#3 Add minimal validation, CI, and paper folder structure](https://github.com/Shoko-official/modern-llm-systems-paper/issues/3)

### Execution Order

1. Complete issue #1 before adding templates or structure.
2. Complete issue #2 before opening paper content PRs.
3. Complete issue #3 before drafting sections or adding figures.
4. Return to the global sequence before starting architecture taxonomy or decision matrix work.

No scientific content should be added during Milestone 0.

## Acceptance Criteria

Milestone 0 is complete when:

* the paper repository role is documented;
* citation and claim rules are documented;
* figure rules are documented;
* issue and MR/PR templates exist;
* minimal validation commands exist;
* minimal CI exists;
* initial folders for paper, sections, figures, references, scripts, and tests exist;
* no scientific sections, real bibliography entries, or figures have been added.

## Later Milestones

Later milestones are placeholders until Milestone 0 is complete.

Expected sequence:

1. Define a minimal paper skeleton.
2. Define citation integration with the research ledger.
3. Add section stubs without scientific claims.
4. Add a first citation validation pass.
5. Add reproducible figure workflow.
6. Draft sections only after research evidence is available.
7. Add LaTeX build and arXiv packaging once structure stabilizes.

Any change to paper structure, citation format, or figure generation must happen in a dedicated issue.
