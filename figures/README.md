# Figures

This directory is reserved for paper figures and diagram sources.

Figures must stay reproducible and reviewable. Mermaid sources and
Python-generated images are the default allowed formats.

## Expected Role

Future files in this directory may contain:

* Mermaid diagram sources;
* generated figure outputs;
* figure notes needed by the paper;
* references from paper sections to figure files.

## Current Limits

Do not add figures, screenshots, external images, or temporary generation
scripts from this layout issue.
